The site you are reading right now: a single-page portfolio built to be understood in under a minute, generated by Hugo, and shipped as plain static files with no additional JavaScript, frameworks, or dependencies.

CSS is inlined into the head and a GitHub Actions workflow builds and deploys it to GitHub Pages, keeping it within a lightweight-web budget (1MB Club style). It stays readable with CSS disabled and every colour meets AA contrast: the constraints are all visible in the source rather than merely described.
