A dependency-free REST API and web interface that validates identification numbers (credit cards, IMEI, and others) with the Luhn algorithm, built with Clean Architecture.

While technically redundant (the specific implementation can be done frontend-only)... Pedagogically? Worth it for getting back into Go.
